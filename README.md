# Darshan Thorath — Hacker Theme Portfolio

## Run locally
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Features
- Dark terminal / cyberpunk visual style
- Lightweight Matrix-style animated background
- Typing role animation
- Interactive portfolio demo terminal (only runs safe, predefined display commands; it does not execute shell commands)
- Responsive mobile navigation
- Animated project cards and scroll reveals
- Plain HTML, CSS, JavaScript; no build step or backend required

## Personalize before publishing
- Confirm your email and replace the generic LinkedIn/GitHub URLs in `index.html`.
- Add actual repository and live demo links to your projects.
- Confirm education dates and internship details.
- Add a real resume file and link if you want a resume download button.
- Project descriptions should match the features you have actually implemented.

## Publish for free using GitHub Pages
1. Sign in to GitHub and create a public repository named `darshan-portfolio` (or `YOURUSERNAME.github.io` for a user site).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the publish job to finish and open the URL shown in Settings → Pages. A project repository usually uses `https://YOURUSERNAME.github.io/darshan-portfolio/`.
6. To use a custom domain, purchase a domain and configure it in Settings → Pages and your domain provider's DNS settings.

GitHub Pages hosts static HTML/CSS/JS; this site does not need a backend. A custom domain costs money; the GitHub Pages URL is free.
